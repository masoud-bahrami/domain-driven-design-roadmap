# Ubiquitous Language

Ubiquitous Language is the shared language used by domain experts and the software team within a Bounded Context. It should appear consistently in conversations, examples, documentation, and the domain model.

It is not simply a glossary that is written once and forgotten. It evolves as the team discovers distinctions, challenges assumptions, and refines the model. When a term is ambiguous, ask what people mean in a concrete scenario. When the model changes, update the code and the language together.

A useful practice is to capture terms with definitions, examples, counterexamples, and context. Avoid forcing identical terms across contexts when the underlying concepts differ.
