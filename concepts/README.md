# Concepts

This section provides deeper explanations of the concepts, patterns, and practices used throughout the Domain-Driven Design roadmap.

These pages are reference material, not isolated topics to memorize or a sequence to complete independently. Their meaning becomes clearer when explored through concrete business scenarios and within the boundaries of a specific domain model and Bounded Context.

Ubiquitous Language connects these concepts: it provides the shared understanding through which a team discovers, discusses, and expresses its domain model.
