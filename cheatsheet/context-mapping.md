# Context Mapping

A Context Map describes relationships between Bounded Contexts. Patterns in the source material include Shared Kernel, Customer-Supplier, Conformist, Anti-Corruption Layer, Separate Ways, and Published Language.

For every relationship, document: upstream and downstream roles, ownership, shared assumptions, integration mechanism, translation responsibility, change coordination, and known risks. Select a pattern based on the actual relationship and power dynamics, not by diagram aesthetics.
