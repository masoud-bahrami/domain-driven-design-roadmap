### Context Mapping Checklist

- [ ] Identify the Bounded Contexts in scope.
- [ ] Clarify each context's ownership and responsibilities.
- [ ] Identify upstream and downstream relationships.
- [ ] Choose and name the appropriate Context Mapping pattern.
- [ ] Document integration points, protocols, and contracts.
- [ ] Identify translation responsibilities and assumptions shared across boundaries.
- [ ] Draw the Context Map, showing relationships and their direction.
- [ ] Document the rationale, risks, and unresolved questions.
- [ ] Review the map when context boundaries, ownership, or dependencies change.
