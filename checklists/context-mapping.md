# Context Mapping Checklist

- [ ] Identify the Bounded Contexts in scope.
- [ ] Clarify ownership and responsibilities.
- [ ] Identify upstream and downstream relationships.
- [ ] Choose and name the relationship pattern.
- [ ] Document integration points, protocols, and contracts.
- [ ] Record translation responsibilities and shared assumptions.
- [ ] Draw the Context Map.
- [ ] Document rationale, risks, and unresolved questions.
- [ ] Review the map when boundaries or dependencies change.
